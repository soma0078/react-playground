# Feel

**느낌을 나타내는 말 ↔ 실제 파라미터.** 이 저장소에서 가장 중요한 문서다.
"부드럽게"는 사람마다, 실행마다 다른 결과를 낸다. 여기 적힌 말은 쓰인 곳의 숫자로 고정된다.

처음부터 이 말들을 알고 요청할 필요는 없다. 평소 말로 요청하면 AI가 변형 2~3개를 만들고,
그중 고른 것의 수치가 **요청에 쓴 그 말**과 짝지어져 여기에 쌓인다. 쌓일수록 같은 말이 같은 결과를 낸다.

- **확인됨**: 결과를 보고 채택했다 (`taste.md`에 근거)
- **가설**: 코드에서 역으로 붙인 이름. 고른 적 없음

`(Lab)`은 Motions 갤러리가 아니라 기존 실험 페이지의 컴포넌트에서 가져온 어휘라는 뜻이다.

| 말                | 파라미터                                                                            | 상태   | 쓰인 곳               |
| ----------------- | ----------------------------------------------------------------------------------- | ------ | --------------------- |
| 지그시 내려앉는   | `ease-out-quart` 1.1s + 투명도만 0.35s linear로 먼저                                | 가설   | ScrollStackHero (Lab) |
| 또렷하게 올라오는 | 투명도 없이 `overflow: hidden` 틀 아래 110%에서 0.9s `ease-out-quart`, 줄마다 0.12s | 확인됨 | text-mask-reveal      |
| 통 튕기는         | spring `stiffness 220, damping 12, mass 0.6`                                        | 확인됨 | magnetic-button       |
| 고무줄 같은       | 끌 범위 0 + 탄성 0.35, 복귀 bounce `400 / 14`                                       | 확인됨 | elastic-drag          |

## 새 말을 추가할 때

1. 말은 **요청에 실제로 쓰인 표현**을 그대로 쓴다 ("몽글몽글", "휙", "티 안 나게"). 다듬지 않는다
2. 같은 뜻의 말이 이미 있으면 새 줄을 만들지 말고 그 줄에 표현을 덧붙인다
3. 반드시 숫자를 적는다. 숫자 없는 말은 추가하지 않는다
4. 채택된 결과의 수치면 **확인됨**, 아니면 **가설**
